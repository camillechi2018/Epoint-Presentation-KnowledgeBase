# 六项并列长文案

蓝白和红白各有一份单页来源稿及一份原生正文资产。正文为两列三行，从左到右、逐行阅读。每项必填一个标题和一段说明，数量固定为六。

| 字段 | 容量 |
| --- | --- |
| 页标题 | 单行，42 个视觉宽度单位 |
| 每项标题 | 单行，18 字符且不超过 36 个视觉宽度单位 |
| 每项说明 | 16 pt 常规正文，最多 3 行，每行 50 个视觉宽度单位，最多 75 字符含换行 |

全角字符一般计 2 个宽度单位，半角字符一般计 1 个宽度单位。正文单段原文在试填时按需换行。蓝红两版正文资产不含页标题、页眉线和 Logo，整页来源稿保留这三个对象，供关闭公共页眉装配时使用。
